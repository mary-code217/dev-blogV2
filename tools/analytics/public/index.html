GOOGLE ANALYTICS

통계를 읽을 권한 연결하기

GA 방문 데이터는 이미 수집 중입니다. 아래 연결은 데이터를 읽기 위한 설정이며, 한 번만 하면 됩니다.

  1. Google Cloud 프로젝트를 선택하거나 만들고 Google Analytics Data API를 활성화합니다. 속성 자동 찾기를 사용하려면 Admin API도 활성화합니다.
  2. 서비스 계정을 만들고 계정의 키 → 키 추가 → 새 키 만들기 → JSON에서 키 파일을 내려받습니다. 프로젝트 역할은 부여하지 않아도 됩니다.
  3. GA 관리 → 속성 액세스 관리에서 서비스 계정 이메일을 뷰어로 추가합니다.
  4. 아래에서 JSON 파일을 선택하고 연결합니다. 키는 이 PC에만 저장되고 화면이나 공개 저장소에 노출되지 않습니다.
인증 키는 채팅에 보내지 마세요.

샘플 데이터로 보는 화면실제 글 제목에 예시 수치를 넣었습니다. GA 통계가 아닙니다.
어제까지의 완료된 날짜를 비교합니다.
